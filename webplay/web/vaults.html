Jump to a room

What Palace mode does. It sets buffer and coyote to zero — the shipped settings of the game this replaces. A jump press was thrown away on any frame the runner was not already on the ground, so a tap arriving mid-air vanished. Android touch latency is three to nine frames, so anticipating a landing never worked; only late taps did. Sixteen tests passed throughout, because they fed the physics the perfect frame a human cannot produce.

Watch the margin readout while you play in Palace mode: it barely moves, and stays green. That is not a fault in the number — margin only ever presses jump from solid ground, so it never meets the case buffering exists for. It is the honest reason one green measurement is never proof a game can be played. You have to press the button.
