—The Vaults

One room a day, one clock. Deaths are free — you restart at the entrance and the clock keeps running, so dying costs you only the thing you cannot get back. Finish it and you can send the run itself as a link: your friend races the attempt you actually had.

Your time today is the first run you finish; after that the room stays open to practise on. A shared link carries the run itself — every button you pressed, a few dozen characters of it — and nothing else, because the physics is deterministic and the rest can be recomputed. There is no server keeping any of this. The tuning harness is the same game with the dials exposed.
